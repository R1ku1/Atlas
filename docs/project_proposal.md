# Proposal

## Problem Statement

Modern codebases are increasingly large and complex. Developers spend significant time navigating unfamiliar repositories. Atlas aims to provide a privacy focused local assisstant that helps developers understand, search and interact with their codebases using local language models.

## Goals

What should Atlas do?

### Primary Goals

- Index Software Repositories
- Allow semantic code search
- Answer questions about codebases
- Run completely locally

### Non Goals

- Not trying to replace professional coding assisstants
- Not training a new LLM
- Not supporting every programming language initially
